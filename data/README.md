# My notebook

Real information belongs here only in your private installation. The template starts empty except for instructions.

- `areas/`: ongoing responsibilities, Markdown.
- `projects/`: projects with defined outcomes, JSON.
- `tasks/`: tasks and inbox, JSON.
- `notes/`: notes and conversation summaries, Markdown.
- `activity/`: daily activity logs, JSON.
- `calendar/`: optional future calendar format.

All personal content in `data/` is excluded from exports. See `docs/data-model.md` for formats and relationships.
