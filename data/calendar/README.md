# Calendar - optional future integration

No calendar connection or automatic synchronization is installed.

Calendar appointments should be separate from task deadlines and planned work dates. A future event format needs a stable ID, title, start, end, timezone, and optional task link. Add format validation before saving real events.

A possible first setup lets repository files drive a separate Google calendar through Actions. It requires Google authorization and credentials in Actions Secrets. Two-way synchronization needs baselines and conflict rules. Google handles notifications; Actions is not an exact reminder clock.
